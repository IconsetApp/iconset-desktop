# Iconset

Downloads for Iconset 3 and later, the SVG icon manager for Mac and Windows.

Get the latest version at [iconset.io](https://iconset.io), or pick one from [Releases](https://github.com/IconsetApp/iconset-desktop/releases). Once installed, Iconset keeps itself up to date.

Looking for Iconset 2? It's at [IconsetApp/iconset](https://github.com/IconsetApp/iconset/releases/latest).
